First release of **CanonDirectPrint**: print photos from a Sony α7 (ILCE-7) straight to a Canon SELPHY or Canon Ivy 2.

## Downloads

| File | Install on |
|---|---|
| `CanonDirectPrint-release-0.1.0.apk` | The camera, with [Sony-PMCA-RE](https://github.com/ma1co/Sony-PMCA-RE): `pmca-console install -f CanonDirectPrint-release-0.1.0.apk` |
| `CanonDirectPrintBridge-release-0.1.0.apk` | An Android phone (Android 6+), only needed for the Ivy 2 |
| `SHA256SUMS.txt` | Checksums of both APKs |

See the [README](https://github.com/ben-hawks/OpenMemories-CanonDirectPrint#readme) for setup.

## Features

- **Canon SELPHY** over Wi-Fi, no bridge: the camera joins the printer's *Direct Connection* network or a shared Wi-Fi. It prints over AirPrint/IPP, with Canon's CPNP protocol as a fallback for SELPHYs without AirPrint (CP900/CP910).
- **Canon Ivy 2** through a small Wi-Fi to Bluetooth bridge: the *CanonDirectPrint Bridge* phone app (the phone's hotspot is the camera's network), a Raspberry Pi script, or an experimental ESP32 sketch.
- **Print options on the camera:** borderless (*Fill*) or white border (*Fit*), automatic rotation to fit the sheet, copies, and for the SELPHY a *High* quality mode that renders from the full-resolution photo within the camera's 24 MB of app memory.
- **Printer status:** paper, ink and battery, and the Ivy 2's auto power off.
- **Automatic discovery** of the printer and bridge, so there is no typing on the camera. Optional `CDPRINT/CONFIG.TXT` for fixed addresses.

## Notes

- Unofficial community project, not affiliated with Canon or Sony.
- If something does not work, please open an issue and attach `CDPRINT/LOG.TXT` from the memory card. Use a card reader or USB *Mass Storage* mode; MTP only shows photos.
